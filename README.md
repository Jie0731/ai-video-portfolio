# John Jerald AI Video Portfolio

## Local preview
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Upload this folder to a GitHub repository, or import the folder with the Vercel CLI.
2. In Vercel, create a new project and select the repository.
3. Framework preset: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

The Google Drive portfolio folder is already linked throughout the site.
